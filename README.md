# Numpy-Array-Exercise
# 🔢 NumPy Arrays – Class Exercise (Randomly Generated Data)

This repository contains a Jupyter Notebook focused on practicing **NumPy array operations** using randomly generated numerical datas.
The notebook covers all essential NumPy concepts — from array creation to reshaping to mathematical operations.

## 📚 Topics Covered

### 🧱 **Array Creation**

* Creating arrays using `np.array()`
### 🔍 **Indexing & Slicing**

* Accessing elements by index
* Slicing rows & columns
* Using negative indexing
* Fancy indexing & filtering

### 🛠️ **Reshaping & Transformations**

* Changing array dimensions using `reshape()`
* Transposing arrays
* Stacking arrays (horizontal & vertical stacking)

### 🔢 **Math & Stats with NumPy**

* Element-wise operations
* Array-wise addition, subtraction, multiplication, division
* Statistical functions (mean, median, std, var)
* Summation across axes
* Dot product & basic matrix operations

### ⚙️ **Utility Operations**

* Checking array shapes & dtypes
* Broadcasting concepts

## 🎯 Key Learnings

This exercise helped me understand:

* How NumPy handles multidimensional numeric data
* Core array operations and transformations
* Differences between Python lists and NumPy arrays
* Efficient mathematical computations using vectorization
* Using random data to simulate real numerical datasets

## 🚀 How to Run

1. Clone/download the repo
2. Open the `.ipynb` file in Jupyter Notebook, VS Code, or Google Colab
3. Run cells sequentially to view results and explanations�
